Tranquility installer

A tiny dumbphone OS written in Rust. Try it on a cheap, unlockable Android phone, straight from this page.

Experimental: not yet tested on real phones. On a phone it can boot and draw its interface through the bootloader's display, then run a short demo. There are no drivers yet for the phone's modem, buttons, touchscreen, sound or flash storage, so it can't make real calls or texts there. On phones marked keeps data, messages and contacts survive a restart from Settings → Restart (kept in RAM the phone preserves across restarts), but not a power-off. Start with Try it, which changes nothing on the phone.
This browser can't talk to USB devices. Use Chrome, Edge, Brave or another Chromium browser on a computer (or on another Android phone with a USB-C cable). Firefox and Safari don't support WebUSB.

  1. Pick your phone

  2. Get it ready

    • Back up anything you care about. Unlocking the bootloader erases the phone.
    • Charge it to at least 50%.
    • In Android: Settings → About phone → tap Build number 7 times, then Settings → System → Developer options → turn on OEM unlocking.
    • Put the phone in fastboot mode: pick a phone above Or, with USB debugging on: adb reboot bootloader
    • Connect it to this computer with a data USB cable.
    Linux or Windows doesn't see the phone?

    Linux: your user needs access to the device. Install your distribution's android-udev-rules package (or add a udev rule for the phone's USB vendor ID), then unplug and replug.

    Windows: install Google's USB driver (it binds fastboot devices to WinUSB), or use Zadig to assign WinUSB to the fastboot interface.

    Close any other program using the phone (Android Studio, adb, another tab with this page).

  3. Connect

  4. Unlock the bootloader

    This erases all data on the phone. You will confirm on the phone itself with the volume and power keys.

  5. Try it safe

    Sends Tranquility to the phone's memory and starts it. Nothing is written to storage: hold the power button for ~10 seconds to go back to Android.

  6. Install replaces Android

    Writes Tranquility to the boot partition of the active slot, so Android won't start until you restore the original boot image. Get your phone's stock boot.img from its official factory image before you do this.

  7. Restore Android

    Flash your phone's original boot.img back.

Prefer the command line?

for the selected phone, then:

fastboot boot tranquility-<phone>.img

No phone? Run it in QEMU: make run (terminal) or make run-gui (window, sound, saved data).
